# Module 08 — Team Competition

Module này là operations handbook cho đội 2–3 người: phân vai, chia giờ, quản lý notebook, chốt submission và đóng gói FINAL. Đây là tài liệu hỗ trợ ngoài manifest 48 chương; luật cụ thể phải lấy từ `docs/COMPETITION_PROFILES.md` và thông báo mới nhất của ban tổ chức.

## Dùng trước ngày thi

1. Chốt vai chính/phụ trong `team_roles.md`.
2. Chạy một mock 4h hoặc 6h theo `workflow_4h_6h.md`.
3. Dùng `notebook_checklist.md` để kiểm tra Restart & Run All.
4. Tập đóng gói theo `final_folder_template.md` trên dữ liệu giả.
5. Sau mock, điền `technical_report_template.md` trong tối đa 20 phút.
6. Dùng `contest_toolkit.md` để chốt stack và emergency playbook trước ngày thi.
