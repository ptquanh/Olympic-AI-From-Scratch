# Module 07 — Olympiad Problems

Module này là lớp luyện đề ngoài manifest 48 chương. Repo chỉ giữ **link nguồn + metadata + protocol luyện + postmortem**, không mirror đề, dataset, notebook hay code lời giải của cuộc thi.

## Cách học

1. Làm `diagnostic/` trước để tìm lỗ hổng.
2. Chọn một kỳ thi trong `problem_index.md` theo kỹ năng muốn luyện.
3. Đọc [practice protocol](practice_protocol.md), mở đề từ **nguồn chính thức**, tạo workspace luyện riêng ngoài repo và đặt timebox.
4. Sau khi hết giờ, điền [postmortem template](postmortem_template.md).
5. Ghi kết quả vào `_dev/real_problem_log.md`; định kỳ tổng hợp gap vào `_dev/curriculum_gap_log.md`.

## Nguyên tắc

- Không chép lại statement, dataset, notebook hoặc code lời giải của cuộc thi; chỉ lưu link gốc và metadata cần để chọn bài.
- Không gọi một lời giải là “official” nếu nguồn không phải ban tổ chức hoặc repository chính thức.
- Luật thi thay đổi theo năm. Luôn đọc statement, rules và environment của đúng kỳ thi trước khi chạy notebook.
- Dữ liệu ngoài repo phải được người học tải theo license và điều khoản của nguồn.
