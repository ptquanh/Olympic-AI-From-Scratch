# AI Challenge PTIT — practice workflow

Nguồn: https://aichallenge.ptit.edu.vn/

Thư mục này không mirror đề, dataset, notebook hoặc code. Workspace làm bài nằm ngoài repo; repo chỉ giữ link và kết quả học tập tổng hợp.

## Timebox gợi ý

- 15 phút: đọc đề + metric + schema.
- 30 phút: EDA và split.
- 45 phút: baseline chạy end-to-end.
- Sau đó mới tuning/ensemble.

Nếu một bài có luật dùng Internet/LLM/package riêng, ghi nguồn chính thức vào postmortem. Kết quả luyện được tổng hợp ở `_dev/real_problem_log.md`.
