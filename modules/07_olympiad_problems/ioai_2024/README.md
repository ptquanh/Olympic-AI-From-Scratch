# IOAI 2024

Nguồn chính thức: https://github.com/IOAI-official/IOAI-2024  
Trang task: https://ioai-official.org/2024-tasks/

IOAI 2024 có Scientific Round gồm at-home và on-site, mỗi phần có task ML, NLP và CV. Trang chính thức cũng cung cấp best-solution notebooks để đối chiếu sau khi tự làm.

## Cách luyện

1. Chọn đúng round và tải task từ nguồn chính thức.
2. Timebox lần đầu: 2 giờ/task; mục tiêu là baseline + validation + submission hợp lệ.
3. Lần hai mới đọc best solution và ghi ba insight mình đã bỏ lỡ.
4. Chuyển insight thành ablation nhỏ trong notebook riêng.

## Postmortem bắt buộc

- Metric và validation mình đã dùng có đúng với task không?
- Bottleneck là data, model, optimization hay thời gian?
- Best solution thắng nhờ model lớn hay nhờ insight/task-specific adaptation?
- Có kỹ thuật nào nên đưa ngược vào Module 06?
