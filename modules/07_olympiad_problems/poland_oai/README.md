# Polish AI Olympiad — OlimpiadaAI

Nguồn tổ chức: https://github.com/OlimpiadaAI  
Edition 2025: https://github.com/OlimpiadaAI/II-OlimpiadaAI  
Training materials: https://github.com/OlimpiadaAI/szkolenia

## Vì sao nên luyện

OlimpiadaAI có nhiều bài nhỏ, đa dạng ML/CV/NLP, phù hợp để luyện insight trước khi làm full contest. Edition 2025 có các nhóm bài như coin detection, hallucination detection, ECG anomaly detection, noisy labels, source extraction, inpainting và unlearning.

## Quy trình

1. Chọn task gần chapter đang học.
2. Đọc environment của chính task đó.
3. Làm baseline trong 30–45 phút.
4. Ghi failure mode trước khi đổi model.
5. Sau khi tự làm, mới mở model solution/write-up nếu repository cung cấp.

Không giả định package/version của Polish OAI giống OlpAI hoặc IOAI.
