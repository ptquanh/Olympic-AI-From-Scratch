# Document AI

> **Track:** Foundation ⚡ | Contest ⭐

## ① Giới thiệu

Văn bản trong thực tế hiếm khi là những đoạn string sạch sẽ. Chúng thường nằm trong file PDF scan, hợp đồng, biên lai, chứng minh nhân dân. Document AI là sự giao thoa giữa CV (xử lý ảnh) và NLP (xử lý chữ) để giải quyết vấn đề này.

## ② Learning Outcomes

- Nắm được các bước trong luồng xử lý Document: Nhận diện vùng văn bản (Layout Analysis) $\rightarrow$ Nhận diện ký tự (OCR) $\rightarrow$ NLP trích xuất thông tin (KIE).
- Gọi API Tesseract (hoặc EasyOCR) cơ bản.
- Biết khái niệm multimodal Transformer như LayoutLM.

## ⑯ Time Estimate

Theory: ~1h, Code: ~1h, Exercises: ~1h
